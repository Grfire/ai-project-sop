# Test pack

See `.cursor/skills/project-test/SKILL.md`.

Fill `runtime.ps1`, `catalog.yaml`, then:

```powershell
.\scripts\run-all.ps1 -Mode full
.\scripts\run-code.ps1       # debug: Mode=code-only
.\scripts\run-product.ps1    # debug: Mode=product-only
```

`runtime.ps1` may set `StartCmd`, `StopCmd`, `HealthUrl`, and
`StartupTimeoutSeconds`. Product regression starts the app when configured,
waits for health, runs Playwright, and executes the optional stop command.
Product dependencies are exact-pinned in `package.json` and
`package-lock.json`; restore them with `npm ci`. `node_modules` is never part
of the template. `last-run.json` is generated by the runner and validated
before regression machine state is updated.

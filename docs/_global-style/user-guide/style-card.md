# Style card — `user-guide`

## Voice
- Language: Chinese by default
- Person / tone: direct second-person instructions; calm and practical
- Formality: clear product documentation, no marketing copy

## Structure
- Title pattern: `<产品名> 用户指南`
- Heading levels used: H1–H3
- Numbering: numbered procedures; bullets for choices and notes
- Opening meta block: audience, version, updated date, source revision

## Patterns
- Tables when: comparing roles, permissions, or field meanings
- Lists when: prerequisites, steps, troubleshooting
- Callouts / 注意: before irreversible or permission-sensitive actions

## Required sections
1. Scope and audience
2. Getting started
3. Task-based workflows
4. Troubleshooting and known limits

## Forbidden
- Invented capabilities, screenshots, URLs, or support channels
- Unexplained internal implementation terms

## Fingerprint (excerpt)
```text
开始前，请确认你的账号具备所需角色。
1. 打开目标页面。
2. 按页面提示完成必填项。
3. 提交后核对结果状态。
若状态与预期不符，请先查看“故障排查”。
```

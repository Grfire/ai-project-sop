# 交付前 Critique

声称完成前按序检查。失败项先修再交付。

## A. 方向

- [ ] 题材与受众清晰，并非通用模板脸
- [ ] 未落入 direction 中的默认脸（除非 brief 要求）
- [ ] 存在且仅突出一个签名元素
- [ ] 文案具体、动作命名一致

## B. 表面

- [ ] brand：首屏预算合格；无英雄浮标；品牌可识别
- [ ] product：层级可扫读；无卡片套卡片装饰
- [ ] mixed：壳与工具区规则未串味

## C. 组件与状态

- [ ] 主按钮层级正确
- [ ] 表单有可见 label；校验时机合理
- [ ] Modal/Drawer 焦点与关闭路径完整
- [ ] 空 / 加载 / 错误态可用
- [ ] 危险操作有确认

## D. 工艺

- [ ] 焦点可见；键盘可达关键路径
- [ ] 动效符合表面默认且可减弱
- [ ] 关键关键无水平误溢出
- [ ] 对比度足够（正文与控件）

## E. 反模式快扫

- [ ] 无紫渐变/玻璃发光堆砌（除非 brief）
- [ ] 无 emoji 当图标
- [ ] 无「点击这里」链接文案
- [ ] 无禁用提交且无原因

## F. 验收方式

- [ ] 代码层：项目既有 lint/type/test（若有）
- [ ] 产品层：用 **`cursor-ide-browser`** 走过主路径（页面、表单、上传、生成、导出、导航等按任务）；无 Browser MCP 时至少打开 `npm run dev` URL 并截图核对

输出时：列出仍存在的问题；零问题时才可声称就绪。

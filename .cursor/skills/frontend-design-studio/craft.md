# 工艺（Craft）

工程向打磨。不指定框架；把规则映射到项目栈。

## 间距与布局

- 用一致的间距尺度（如 4/8 基准）；相关更紧、区块更松
- 固定层叠尺度，避免随意无限 z-index
- 固定底栏/顶栏考虑安全区（刘海/Home 指示）
- 视口高度优先动态视口概念（避免移动浏览器地址栏裁切），而非死守「屏幕高度=布局高度」

## 排版

- 标题避免丑陋折行；正文注重可读宽度
- 数字列用等宽数字观感（tabular）
- 密集 UI 文本溢出要截断或夹行，不能撑破布局
- 不要无意义地字距排版；需要时由 direction 的显示字决策驱动

## 交互与反馈

- 破坏性/不可逆操作必须确认
- 错误出现在动作发生处附近
- 加载：布局可预期时用骨架，而非盲目转圈
- 空态：说明 + 一个明确行动
- 不要禁止粘贴到输入框

## 动效

- brief / brand 表面未要求时：product 少动；brand 最多 2–3 处有意动效
- 优先合成属性（transform、opacity）；避免动画 width/height/top/left/margin/padding
- 交互反馈宜短（约 ≤200ms 量级）；入场可用 ease-out
- 尊重减弱动态偏好；离屏循环动画应停止
- 大面积 blur/backdrop-filter 动画视为有害默认

## 焦点与键盘

- 可见 focus；不要去掉轮廓除非有同等可见替代
- 模态：焦点陷阱；关闭后焦点回到触发器
- 自定义控件前，优先用无障碍原语库

## 响应式

- 至少 375 / 768 / 1024 / 1440 心智检查
- 触控目标足够大（约 ≥44px 心智）
- 产品表单以单列扫读为默认

## 性能观

- 不为「感觉高级」堆阴影与全屏滤镜
- 动画进行中之外不要滥用 will-change

# 表面分流（Surfaces）

先判定再设计。`mixed` = 外层品牌壳 + 内层产品 UI；各层套用对应规则。

## Brand（营销 / 落地 / 作品集 / 品牌站）

- **一个构图：** 首屏是一个完整构图，不是仪表盘
- **品牌优先：** 品牌名是英雄级信号；去掉导航后仍能认出品牌
- **首屏预算：** 通常仅有品牌、一句标题、一句支持句、一组 CTA、一个主视觉
- **禁止首屏堆砌：** 统计条、日程、地址块、促销碎片、元数据行
- **主视觉：** 默认全出血；不要默认做成内嵌圆角媒体卡片或拼贴
- **禁止英雄叠加物：** 不在主视觉上贴浮标、徽章、促销贴纸
- **卡片：** 首屏禁用卡片；仅当卡片是交互容器且去掉边框/阴影会损害理解时才用
- **动效：** 2–3 处有意动效建立存在感与层级，禁噪音
- **旋钮默认：** variance 6–8 / motion 5–7 / density 3–5

## Product（SaaS / 后台 / 设置 / 工具）

- **清晰优先于表演：** 扫读、层级、表单效率第一
- **一区一事：** 每区一个目的、一个标题、通常一句说明
- **密度：** 信息可密，但要对齐与节奏；避免纯装饰卡片套卡片
- **导航可见：** 桌面避免无必要汉堡藏导航
- **状态完整：** 空、加载、错误、禁用都要可理解
- **动效默认克制：** 未点名则少动；反馈 ≤ 约 200ms 量级的交互反馈优先
- **旋钮默认：** variance 3–5 / motion 2–4 / density 5–8

## Mixed

1. 外壳（落地/splash）→ Brand 规则  
2. 登录后 / 工具区 → Product 规则  
3. 不要把 Brand 的英雄预算套进数据密集后台

## 快速判定

| 信号 | 表面 |
|------|------|
| 转化、叙事、作品展示、品牌印象 | brand |
| 任务完成、配置、数据操作、权限 | product |
| 两者同页分区 | mixed |

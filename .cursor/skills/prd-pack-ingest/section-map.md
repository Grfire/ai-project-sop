# PRD 章节 → 设计关注点

标准 12 节（见 requirements-analysis / `_template`）。缺节时在工作简报标明。

| 节 | 设计/原型要抽出的 |
|----|-------------------|
| 1 背景与问题 | 题材、受众语气；非实现细节 |
| 2 目标与成功标准 | 演示闭环 vs 指标型验收；原型做到哪一档 |
| 3 用户与场景 | 角色、导航显隐、主路径 S-xx |
| 4 范围 | In/Out、分期、双模是否只做门户 |
| 5 功能设计 | F-xx 清单、依赖、业务规则、参考范式 |
| 6 页面与交互 | P-xx、IA、空/载/错态、关键文案 |
| 7 数据与对象 | Mock 字段、列表/详情形状 |
| 8 边界与接口 | 原型是否假接口；禁暴露的外部登录/品牌 |
| 9 非功能 | 密度、部署假设（一般不挡静态原型） |
| 10 验收 | AC-xx ↔ sample-data / 浏览器用例 |
| 11 里程碑 | 分期交付切分 |
| 12 开放问题 | 挡设计的 Q-xx 优先问用户 |

## 检索辅助

读大 PRD 时优先 Grep：

- `^## |^### `
- `P-\d+|F-\d+|AC-\d+|S-\d+`
- `页面|导航|信息架构|角色|In Scope|Out of Scope`
- 项目特定禁用词 / 底座品牌名
